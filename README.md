## 🌐 Deploying to GitHub Pages (Step-by-Step)

This website uses native ES Modules, modern HTML5, and vanilla CSS3 with **zero build steps** required. It deploys natively to GitHub Pages in seconds:

1. **Initialize Git & Push to GitHub**:
   ```bash
   git init
   git add .
   git commit -m "Initial release: Premium AI Engineer Portfolio"
   git branch -M main
   git remote add origin https://github.com/martin22308/portfolio.git
   git push -u origin main
   ```

2. **Enable GitHub Pages**:
   - Go to your repository on GitHub: `https://github.com/martin22308/portfolio`
   - Navigate to **Settings** → **Pages** (under Code and automation).
   - Under **Build and deployment** > **Source**, select **Deploy from a branch**.
   - Under **Branch**, select `main` and folder `/ (root)`.
   - Click **Save**.

3. **Live URL**:
   Your website will be live in ~60 seconds at:
   `https://martin22308.github.io/portfolio/`
